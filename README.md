# CircuitDeck

Interactive 3D electronics projects in the browser: wire parts to a 3D board, run the code, and watch it work.

- **ESP32 track** (`/`): 20 lessons, Arduino C++.
- **Raspberry Pi 5 track** (`/pi5/`): 29 projects, Python (gpiozero, picamera2 and the AI Kit). Each has a 3D scene, a simulated run, tabs, a "What to buy" list and a difficulty tag.
- **Sandbox** (`/sandbox/`): build your own ESP32 or Pi 5 circuit.
  - Add parts from 33 types and wire them by clicking pins.
  - Voltage and pin-conflict checks, generated code (C++ or Python), a simulated run, a wiring list and a parts list.
  - Saves in localStorage, exports and imports JSON, and makes share links (a compressed circuit in the URL hash).
  - 12 starter templates, including traffic light, weather station, robot car, door lock and AI camera.
- **Gallery** (`/gallery/`): every lesson, project and template, filterable by track and difficulty.
- A light/dark theme (light by default, remembered per browser), plus a track switcher on every page.

Live: https://circuitdeck.vercel.app

## Run locally
    python3 serve.py 8080      # then open http://localhost:8080/

The site is fully static and has no backend; progress and settings live in `localStorage`. It must be served over HTTP from the web root, because the modules use root-absolute paths.
`serve.py` (Python 3 standard library) behaves like the static host: it serves `index.html` for directories and `404.html` with an HTTP 404 status.

## Layout
- `index.html`, `assets/`: the ESP32 track (a prebuilt Vite + three.js r186 bundle, with only branding strings changed)
- `pi5/`, `sandbox/`: page shells generated by `_tools/mkpage.py`
- `src/core/`: the shared stage, UI, boards and parts
- `src/pi5/`: Pi 5 projects
- `src/sandbox/`: circuit model, checks, codegen, simulation, templates and storage
- `gallery/`: the gallery page, `data.json` and the ESP32 thumbnails
- `shared/`: the track switcher and theme toggle (`chrome.js`, `cd.css`), plus page and gallery CSS
- `vendor/three/`: three.js module and OrbitControls (used by the new pages through an importmap)
- `_raw/`, `_compare/`, `_tools/`: local capture, test and build material (not deployed, git-ignored)

## Deploy
This is a static site: Vercel needs no framework preset and no build command, with the repo root as the output directory.
